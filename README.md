# Salt-map

Maps tell you the route. salt-map tells you what it costs.

A free, open-source browser extension for Bengaluru that shows:
- Which BMTC buses to take (bus X, then bus Y) and the fare
- Approximate auto, Uber and Rapido prices for the same trip

## Status
Work in progress. Starting with Bengaluru only.
